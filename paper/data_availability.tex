{\large\bfseries Data Availability Statement}

\emph{Publication-aware prediction of battery material properties from literature-extracted data}\\
Sunraj Patel

The Huang--Cole battery materials database analysed in this study is publicly available from figshare at \url{https://doi.org/10.6084/m9.figshare.11888115}.

The code for data preparation, model training, evaluation and the adapted comparison pipelines, the frozen element list, the split fingerprints and all result tables are archived on Zenodo (version v1.0.0) at \url{https://doi.org/10.5281/zenodo.24500203} and developed at \url{https://github.com/sunraj-patel/battery-prediction}.

The adapted pipelines reuse code from \url{https://github.com/lamalab-org/clever-materials-hans} (MIT licence) and data files from \url{https://github.com/ZoraZhuang/battery_datasets} (GPL-3.0).
